# polykybd-claude

Shared Claude Code instructions and skills for every PolyKybd repo. Attach this repo to
every Claude Code environment and session that works on a PolyKybd repo; its
`CLAUDE.md` and `.claude/skills/` then load like any other attached repo's.

- `CLAUDE.md`: the rules for all repos, and which file to follow.
- `docs/`: shared detail (review conventions, branching, releases, context cost,
  the exhibition checklist).
- `docs/archive/`: every repo's CLAUDE.md as it was before the 2026-10-10 consolidation.
- `.claude/skills/`: the cross-repo skills, one copy each.
