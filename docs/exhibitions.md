# Exhibitions and shows: checklist

Notes for the next time PolyKybd is shown at an exhibition, a meetup or a show.

## Before you leave

- [ ] Pack deskmats. A keyboard on a deskmat looks much better than one on a bare table.
- [ ] Print signs for each keyboard: the model, the switches, and the other parts a
      visitor asks about.
- [ ] Pack a power bank.
- [ ] Prepare an intro that runs in an infinite loop and needs no interaction. It
      attracts people while you are talking to someone else.
- [ ] Pack the give-aways.

## At the venue

- [ ] Arrive ahead of time and go through this checklist.
- [ ] Set the brightness to maximum on every keyboard that has no brightness sensor.
      Set the brightness in the host program to maximum too.
- [ ] Start the intro loop.
- [ ] Put the give-aways out.
